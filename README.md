# Horse Race

A minimal horse race game of chance for the terminal.

🏇


## How to Play

`$ ./horse-race <number-of-horses>`

<img src="https://github.com/rodrigo-pariente/horse-race/blob/main/img/screencapture_game.gif" alt="The game screencapture" width="900" align="center">


## Build from Source

### Linux

With gcc:

`$ gcc horse_race.c -o horse-race -lm`


## Modify Parameters

Parameters such as STEP_TIME and TRACK_SIZE are constants in the `horse_race.c` file, modifying it can lead to different game experiences, just remember to rebuild after changes.
